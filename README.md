# flashback-atack
今すぐできるフラッシュバックの応急処置情報サイト

## ツール一覧

- **ガイド（index.html）**: つらさをやわらげるセルフケアのヒント集。
- **ロードマップ（roadmap.html）**: 回復のステップを俯瞰できるナビゲーション。
- **トリガー記録（trigger-log.html）**: フラッシュバックのきっかけを端末内に素早く記録。
- **キャラクターマネージャー（character-manager.html）**: 自分を責める声をキャラクターとして外に置き、情報を整理・保存するツール。入力内容はブラウザのローカルストレージにのみ保存され、他の場所へ送信されません。

キャラクターマネージャーでは複数の責める声キャラクターを登録・編集・削除できます。フィールドに必要事項を入力して保存すると一覧にカードが作成され、いつでも距離を取って見直せます。データは同じブラウザのローカルストレージ内に保持されるため、端末を変更すると表示されません。必要に応じてエクスポートしておきたい場合は、別途ブラウザのツールなどでバックアップしてください。
