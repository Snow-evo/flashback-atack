Design Tokens

All visual decisions flow from the shared CSS custom properties declared in styles.css. Use them whenever you introduce a new color, radius, spacing value, or shadow so the live site and this playground stay aligned.

Palette

--accent #ed7a7a
--accent-soft #f6b6aa
--accent-green #62bba1
--accent-orange #ff8a3d
--card-bg Frosted glass
--bg-gradient Background gradient

Apply colors via the token names, e.g. color: var(--text-muted); or background: var(--accent-green-soft);.

Spacing Scale

Token Pixels Usage
--space-sm 8px Compact gaps, pill padding
--space-md 12.8px Standard text spacing
--space-lg 16px Card content rhythm
--space-xl 19.2px Section padding
--space-4xl 28.8px Large layout offsets
Utilities: .u-padding-md, .u-padding-xl, .u-stack-md Structure classes such as .inner and .surface-card also consume this scale.

Radius & Shadows

--radius-4xl Primary card corner
--radius-full Pill buttons
--shadow-soft Default elevation
--shadow-card Feature cards
Utilities: .u-radius-4xl, .u-radius-pill, .u-shadow-soft

Typography

The experience pairs the serif headline font Playfair Display with the sans-serif body font Noto Sans JP. Keep hierarchy by following the clamp-based scale below.

ヒーローヘッダー / Hero Title

class: .hero-title — clamp(2rem, 5vw, 2.8rem)

サイトの最初に登場する印象的な見出し。Playfair Display をベースに、柔らかい行間で安心感を演出します。

セクション見出し / Section Title

class: .section-title — clamp(1.45rem, 2.8vw, 1.85rem)

セクション導入に使用。.section-description で補足テキストを続け、読みやすさを保ちます。

本文スタイル / Body Copy

element: <p> — font-family: var(--body-font); line-height: 1.7

五感のグラウンディングや呼吸の調整など、どのテクニックも「今ここ」に戻るための小さなステップです。文章は短く、 安心を感じられる言葉選びを心掛けます。
